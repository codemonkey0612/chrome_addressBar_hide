MATCHING URL COLORS — EXPERIMENTAL

Install in desktop Chrome:
1. Extract the ZIP into a permanent folder.
2. Open chrome://extensions
3. Enable Developer mode.
4. Click Load unpacked and select the folder containing manifest.json.

This theme requests identical address-field text and background RGB values: 32,33,36 (#202124). Tabs and toolbar controls use readable colors. It contains no scripts or permissions.

Chrome may adjust the background, text, URL portions, selection or focus colors. The URL may remain visible. This package has been checked as JSON but has not been visually tested in Chrome. It does not remove the address bar or its space.

Remove: Chrome Settings > Appearance > Reset to default (next to Theme).
